# Alpha Agency Homepage — 6C Framework Build

## Executive Overview
A full homepage architecture for Alpha Agency balancing crystal-clear messaging for tradies, service businesses, and professional firms with a premium futuristic aesthetic. Copy stays plain-spoken while the interface signals high-tech capability.

## Technical Implementation Notes
- **Stack:** Next.js or Astro for performance and animation control.
- **Styling:** Tailwind CSS + custom CSS for flashlight and gradient-follow effects.
- **Animation:** Framer Motion or GSAP; GPU-accelerated transforms/opacity; lazy-load below the fold; optimise assets (WebP, responsive sizes); target total page weight under 2MB.

## Risk & Mitigation
- Over-animation distracts from conversion → keep all motion subtle and secondary to copy.
- High-tech aesthetic may intimidate non-tech users → copy remains plain-spoken; visuals signal “we handle the complexity.”
- Placeholder proof weakens authority → launch with available stats/testimonials; plan early collection of real proof.
- Single CTA limits flexibility → primary “Book Audit” everywhere with optional “See What We Build” for browsers.

## Execution Roadmap
1. **Copy Approval (Days 1–3):** Review/refine with stakeholders; lock tone, offer, CTAs.
2. **Design (Days 4–10):** High-fidelity Figma (desktop/mobile) + animation prototypes.
3. **Development (Days 11–25):** Build, implement animations, ensure mobile QA.
4. **Launch Prep (Days 26–30):** Connect booking (Cal.com/Calendly/GHL); set up GA4/Hotjar; final QA and soft launch.
